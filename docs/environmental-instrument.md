# Environmental instrument notes

TechnoPeace keeps the public site and the playable Sky instrument on separate interaction paths.

- The homepage reads the existing current weather signal for visual-only atmosphere: cloud cover, daylight, estimated sun altitude, humidity, wind, and current rain/precipitation evidence. It does not start or unlock audio.
- Homepage rain visuals are derived only from current rain, showers, or precipitation values. Daily accumulated rainfall remains archival context and is not used to imply that rain is happening now.
- Sky Mode treats the full-screen sky as the performance surface. HUD controls, mixer panels, sequencer cells, links, buttons, and sliders are marked or handled as controls so they do not move the sky pointer or drone.
- Inside Sky Mode, the performance surface opts out of browser panning/overscroll where supported while preserving active pointer tracking and multi-touch Sky voices.
- Audio changes should preserve the place tonic, lower-octave drone support, Chaos kick/bass/hat behavior, hold/polyphony behavior, and sequencer timing.
